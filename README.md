# Дипломная работа: «Разработка бизнес-плана по производству товара (на примере ООО „КУПИШУЗ", г. Москва)»

В репозитории собран генератор итогового файла `ВКР_Купишуз_бизнес_план.docx`,
оформленного в соответствии с мастер-правилами `MainRule` (Times New Roman 14,
межстрочный интервал 1,5, абзацный отступ 1,25 см, поля 30/10/20/20 мм,
чёрный текст, кликабельное оглавление по заголовкам уровней 1–3) и в общем
стиле «ВКР Гарден» (по-главное нумерование таблиц, рисунков и формул;
академический язык изложения; ссылки на источники в квадратных скобках).

## Содержательные правки относительно исходного текста (`DIPLOMNAYA_rabota (2).pdf`)

1. Полностью убраны англоязычные сокращения и латинские термины:
   - NPV → чистый дисконтированный доход (ЧДД);
   - IRR → внутренняя норма доходности (ВНД);
   - PI → индекс рентабельности инвестиций (ИРИ);
   - DPP → дисконтированный срок окупаемости (ДСО);
   - WACC → средневзвешенная стоимость капитала (ССК);
   - ROE, ROA, ROIC, EVA, ARR, CAPM, DSCR, LLCR — заменены русскими формулировками;
   - SWOT-анализ → анализ сильных и слабых сторон, возможностей и угроз;
   - PEST-анализ → анализ политико-правовых, экономических, социально-демографических и технологических факторов макросреды;
   - STP, SKU, B2B, INCOTERMS — переведены на русские эквиваленты;
   - наименование запускаемой собственной торговой марки `Stepful` заменено на отечественное «Тропа».
2. Изменено название параграфа 2.3: вместо «SWOT- и PEST-анализ внешней
   и внутренней среды» — «Стратегический анализ внешней и внутренней среды
   предприятия».
3. Перенумерованы таблицы и формулы по главам (Таблица 1.1, 2.1, 3.1, …;
   формулы (1.1)–(1.5)).
4. Заголовки глав без точки после номера («Глава 1 Теоретические…»).
5. Заголовки структурных элементов («ОГЛАВЛЕНИЕ», «ВВЕДЕНИЕ», «ЗАКЛЮЧЕНИЕ»,
   «СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ», «ПРИЛОЖЕНИЯ») — прописными, по центру,
   с новой страницы.
6. Стилистика изложения подтянута к стилю «ВКР Гарден» (более длинные
   связные академические предложения, более формальная лексика).

## Состав репозитория

| Файл | Назначение |
| --- | --- |
| `build_diploma_docx.py` | Генератор: настройка стилей, страниц, титульный лист, оглавление, введение; точка входа `main()` |
| `content_ch1.py` | Глава 1 (теоретические и методические основы) |
| `content_ch2.py` | Глава 2 (анализ деятельности ООО «КУПИШУЗ»), включая обновлённый параграф 2.3 |
| `content_ch3.py` | Глава 3 (бизнес-план торговой марки «Тропа») |
| `content_back.py` | Заключение, список использованных источников, приложения А–Г |
| `requirements.txt` | Зависимости |
| `ВКР_Купишуз_бизнес_план.docx` | Итоговый файл, готовый к открытию в Microsoft Word |

## Запуск

```bash
pip install -r requirements.txt
python3 build_diploma_docx.py
```

После сборки откройте файл в Microsoft Word и выполните **«Ссылки → Оглавление →
Обновить целиком»** (или нажмите `F9` на поле оглавления), чтобы автоматически
собрать кликабельное оглавление с реальными номерами страниц.
